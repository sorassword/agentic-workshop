# Website-Design

## Idee
Die Seite wirkt wie ein gut gesetztes Beraterprofil: ruhig, präzise, mit Zahlen, die man in drei Sekunden sieht.

## Typografie
- Überschriften in einer Serifenschrift (Georgia, "Times New Roman", serif), Text in system-ui.
- Name 72 px, Zwischentitel 28 px, Text 18 px, Zeilenhöhe 1.6. Auf dem Handy Name 44 px.
- Gewichte nur 400 und 600. Keine Großbuchstaben-Labels, keine Emojis.

## Farbe
- Hintergrund #FAFAF7, Text #1B1F1D, Nebentext #5C635F, Linien #E4E6E1.
- Ein Akzent aus der CLAUDE.md oder AGENTS.md für den Button, Links und die wichtigste Zahl je Karte.
- Ein heller Ton des Akzents als Fläche für den Kopfbereich. Keine Verläufe, keine farbigen Schatten.

## Layout
- Kopfbereich über die volle Breite im hellen Akzentton: Name, ein Satz Profil, Button Lebenslauf und Link Kontakt.
- Darunter eine Kennzahlen-Leiste mit drei Zahlen aus meinen Projekten, groß in Serif, darunter kurz, wofür sie stehen.
- Projekte als Liste mit Linien statt Kästen: links Zeitraum, rechts Titel, Rolle, Ergebnis.
- Inhalt maximal 880 px breit, Abstände im 8-px-Raster.
- Auf 390 px Breite alles untereinander, nichts abgeschnitten.

## Prüfen, bevor du fertig meldest
- Gibt es einen Text oder eine Zahl, die ich nicht geliefert habe? Dann raus damit.
- Seite bei 390 px und 1280 px Breite ansehen.
